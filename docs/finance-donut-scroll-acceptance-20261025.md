# 理财双层环形图与编辑弹窗滚动：隔离验收与发布边界

适用范围：`codex/finance-calendar-release` 基于已部署提交 `5f806265394b9e62bcdd0a0211b6c627ac4ca8bd` 的本轮修改。2026-10-25 发布前复核时，远端同名分支与生产 Web 的 revision 均仍为该基线。本轮验收使用隔离 PostgreSQL、合成用户和账单；不代表生产真实 OAuth 操作通过。

## 代码审查

- 复现根因：账单详情与编辑弹窗短暂重叠，原共享 `Dialog` 各自记住并恢复 `html/body` 的内联 `overflow`，后关闭的弹窗可能把另一个弹窗记录的 `hidden` 恢复到页面。修复使用共享令牌栈：首个弹窗保存原状态并上锁，最后一个弹窗卸载时恢复；Esc 只处理栈顶弹窗，`onClose` 回调更新不反复释放/获取锁。账单详情在关闭时同步隐藏，避免路由更新未完成时重开。
- `tags` 仍为完整字符串数组，`description` 仍为用途。新可选 `primaryTag` 仅写入账单 JSON payload；单标签直接用于统计，多标签无主标签归入“未指定主要标签”，无标签归入“未设置标签”。编辑器明确写入空字符串以清除旧主标签，避免服务端增量合并保留旧值。旧记录无此字段仍可读取和保存；分类改名/删除迁移通过展开原 payload 保留标签及主标签。
- 统计以整数分聚合；构成图按日期、关键词、收支方向、账户、金额等基础条件计算，点击类别或标签只改变账单、卡片与其他图表的筛选，保留双层构成上下文。外圈按类别内的统计标签分组，同名标签在不同类别分开。转账不计入支出。接口新增 `tagMode`、`tag` 过滤参数与 `composition` 输出；未新增 Prisma schema 或迁移文件。
