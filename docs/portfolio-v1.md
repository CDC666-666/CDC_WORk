# 公开作品集与统计

作品集、分域配置与媒体功能已通过 PR #13、#14 进入 main；最早的本地预览状态不再作为当前说明。此次文档清理未重新部署或验收生产。

## 内容来源

`data/public-portfolio.ts` 维护获准公开的项目字段，页面通过 `lib/portfolio/public-content.ts` 读取；`data/public-contact.ts` 维护获准公开的联系方式。公开项目为 RoboMaster 全向轮步兵电控、三轴机械臂与达妙电机控制、个人工作台。

页面不枚举私人数据库实体，不读取私人日志、笔记、工程经验或派生快照。未来内容更新先核对是否获准公开，不能把工作台记录直接转成作品集。未知起止日期或未核准字段不推断补齐。

## 页面与媒体

入口包括 `/portfolio`、项目列表与详情、关于、联系和统计页。首页轮播与详情使用获准发布的工程视频、封面及独立文案。视频静音循环，可见时播放，离开视口或后台时暂停，减少动效偏好抑制自动播放。

媒体位于 `public/media/portfolio/`，属于明确授权公开的素材；原始源文件不作为工作台附件发布。公开域名允许相应媒体，私人域名按 Caddy 规则拒绝。联系字段未配置时不显示，二维码不因存在联系方式自动生成。

## 统计与 GitHub 贡献

公开统计只对允许的作品集路径采集，匿名 Cookie 经 HMAC 用于去重；公开接口只返回聚合，不返回访问者标识或私人业务数据。开发与正式统计使用不同数据库。

GitHub 贡献图使用独立服务器端只读配置，不使用工作台账号令牌；请求失败时保留公开链接，不伪造数据。真实令牌不能进入仓库。

## 验证范围

合成数据库及浏览器检查应覆盖统计去重、重复事件、跨日口径、速率限制、不可用时错误状态，以及 1440px/390px 的公开导航、轮播、播放、减少动效和未知项目 404。

公开页面可用不证明私人工作台登录或数据正确；私有 API 应单独核对匿名 401，真实 OAuth 验收另行记录。验收材料不得包含私人记录或截图。域名及发布流程见 [部署说明](public-deployment.md)。
